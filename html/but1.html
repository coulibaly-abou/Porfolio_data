Objectif du projet

L’objectif de cette étude est de réaliser une analyse statistique approfondie des satellites de la constellation Starlink afin de mieux comprendre leur déploiement, leurs caractéristiques orbitales et leur évolution dans le temps.

Le travail consiste à exploiter des données issues de différentes sources, les filtrer, les nettoyer et les analyser à l’aide d’outils comme Python et Excel.

Scraping de données

Les données sont récupérées depuis le site Celestrak, qui fournit des fichiers contenant les informations sur tous les satellites. Comme ces données incluent tous les satellites, un filtrage est nécessaire.

Un script Python est utilisé pour faire du scraping sur le site N2YO afin de récupérer les numéros NORAD des satellites Starlink. Ces identifiants sont ensuite comparés avec ceux du fichier initial pour ne conserver que les satellites Starlink. Le script gère aussi les mises à jour régulières afin de maintenir la base de données à jour et d'assurer la fiabilité des analyses réalisées.

Le traitement inclut la validation des données extraites, la suppression des doublons et le nettoyage des valeurs manquantes. Cela garantit que les analyses statistiques portent sur un échantillon cohérent et que les résultats reflètent fidèlement les caractéristiques de la flotte Starlink.

Cartes du ciel

Deux visualisations ont été réalisées. La première est une carte du ciel globale qui représente tous les satellites présents dans la base de données. Elle permet d’avoir une vue d’ensemble de la répartition des satellites.

La seconde est une carte filtrée, montrant uniquement les satellites Starlink. Elle permet d’observer leur organisation, leur densité et leur distribution dans l’espace. La comparaison des deux cartes permet de situer Starlink parmi l’ensemble des satellites.

Analyse statistique

Après le traitement des données, plusieurs analyses statistiques sont réalisées pour identifier les tendances majeures de la constellation Starlink.

Les analyses univariées décrivent les variables individuellement, tandis que les analyses bivariées permettent d’identifier les relations entre différentes caractéristiques orbitales.

Étude univariée

Cette analyse permet de comprendre la distribution de chaque variable individuellement (moyenne, médiane, dispersion) afin d’identifier les caractéristiques dominantes de la constellation avant de croiser les variables entre elles.
